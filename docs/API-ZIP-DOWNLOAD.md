# 批量与目录 ZIP 下载

## 接口

1. `POST /api/file/createZipDownloadUrl`，登录后以表单提交 `fileIds`（逗号分隔）。成功响应 `data` 为短码。
2. `GET /api/file/downloadZip/{code}`，在 5 分钟内兑换该短码，返回 `application/zip`。下载短码是临时访问凭据，不应公开传播或长期保存。

选中单项时归档下载名为“原名称.zip”，多项为“网盘文件.zip”，使用 UTF-8 文件名响应头。归档内部保留中文与 Unicode 名称，并显式包含空目录。跨目录选中的同名文件自动加 ` (1)` 等后缀；大小写、组合重音冲突使用与复制/移动相同的规则。

目录与其中子项同时选中时只归档一次。仅包含本人正常且完成处理的条目，回收站和已删除项不会恢复到归档。选中目录包含未完成处理的文件时，整个请求拒绝，避免默默遗漏内容。

## 范围与资源限制

- 每次最多 1000 个选择项；完整归档最多 10000 个文件/目录条目。
- 每条归档路径的 UTF-8 编码最多 4096 字节；名称不允许路径分隔符、`..`、绝对路径、控制字符等危险形式。
- 签发时校验文件实体、大小、完整活动目录链，冻结有界的归档清单。兑换时重新校验并比较清单；选中树新增、移除、重命名或文件实体变化时，应重新签发。
- 内容以一个 64KiB 缓冲区逐文件读取和压缩，不把整文件/整包加载到内存，不生成临时 ZIP，也不上传到第三方服务。归档不占用新的网盘容量。
- ZIP 输出总长度预先未知，不支持 Range 续传；失败后需要重新开始。普通单文件下载仍保留原来的 Range 能力。

## 失败与权限撤销

`901` 表示账户或下载授权失效；`600` 表示参数、过期短码或快照变化；`404` 表示文件不可读取；`500` 表示链接存储或输出失败。Redis 写入失败会明确报错，不会返回假成功的短码。签发仅允许 POST，跨站写请求仍受 Origin/Referer 保护。

私有单文件码与 ZIP 码绑定签发时的账户 `sessionVersion`。修改/找回密码、禁用和重新启用账户后，旧私有码永久失效，即使短码尚未过期也不能继续兑换。升级前缺少版本的旧私有码需要重新签发。公共分享码继续实时检查分享状态与所有者状态，不因所有者单纯改密而无故失效。

ZIP 在每个条目和长文件传输过程中复核账户/文件状态，检查文件大小、修改时间，并在存在原始 MD5 时验证实际流出的内容。只有全部完成才写入 ZIP 中央目录。尚未发送响应时返回明确的 JSON 错误；响应已经开始后无法改写 HTTP 状态，此时抛出异常并由容器中断传输，不追加 JSON，也不补成看似成功的部分归档。收到不完整归档后需重新下载。

前端应在签发/开始下载时提示“已开始下载”，不能把短码签发成功当成文件已下载完成。
