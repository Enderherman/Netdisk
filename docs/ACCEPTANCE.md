## 交付规则

- 每个独立功能：实现 → 对应自动化测试 → 更新版本、README 能力说明和 UPDATELOG → 独立提交 → 推送 → 校验远端提交。
- README 说明当前能力、配置和启动；UPDATELOG 记录版本变化；本文件记录验收状态。
- 版本使用语义化版本 `MAJOR.MINOR.PATCH`，两仓库独立版本，使用 `vX.Y.Z` 标签。
- 不能把编译成功、模拟接口测试或页面截图等同于真实端到端业务通过。
- 测试只操作隔离数据库、缓存及工作目录，不改已有业务数据。
