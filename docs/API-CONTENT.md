# 内容预览与下载（0.2.0）

所有地址相对 `/api`。浏览器同源 Cookie 由前端代理传递。

| 地址 | 权限 | 用途 |
| --- | --- | --- |
| `GET /file/content/{fileId}` | 登录且本人正常文件 | 原始内容预览 |
| `GET /showShare/content/{shareId}/{fileId}` | 已提取该分享，实时校验有效期与目录范围 | 分享内容预览 |
| `GET /admin/content/{userId}/{fileId}` | 当前管理员 | 管理端内容预览 |

添加 `?download=true` 强制下载，保留完整中文文件名。原始内容支持图片、PDF、文本及浏览器原生音视频格式；Word/Excel 等不直接渲染时提供下载，不使用第三方在线预览上传私有文件。

- 类型依据原始存储后缀，修改显示文件名不会转换文件内容。
- HTML/SVG/未知类型按附件返回，`nosniff` 防止错误类型执行；文本、代码按纯文本显示。
- 支持单段 `Range`（含末尾/开放范围）、`If-Range`、`HEAD`，越界返回 416。
- 内存缓冲固定 64 KiB，长度与偏移使用 long；3 GB 文件末尾读取已有实测。
- 每次请求重新授权，不缓存私有内容。回收、永久删除、未完成上传、变更分享范围均不能继续读取。
- 历史 `createDownloadUrl` / `download/{code}` 仍兼容；代码兑换时验证当前文件、路径与账号状态。缺少新归属字段的旧下载码需重新签发。
- 缩略图按当前用户实际引用授权；不再允许知道物理路径即可读取。
- 历史 HLS 分片在源记录删除后仍可由有效副本授权；新客户端优先使用原始内容接口。

测试边界：44 项新增测试涵盖真实临时文件、MVC/H2、权限撤销和流式字节边界；ffmpeg 转码及真实浏览器文件预览仍待后续端到端验证。
