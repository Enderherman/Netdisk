# 文件组织接口契约

本文件说明文件浏览、新建目录、重命名、移动与目标目录选择的规则。接口均要求用户登录；操作范围来自当前登录用户，不接收客户端指定的所属用户。

## 名称

名称为 1 至 200 个 Java 字符，支持中文、Unicode 和空格。禁止路径分隔符、控制字符、`/:*?"<>|`、首尾空白、尾点及 Windows 保留名称（如 `CON`、`NUL.txt`）。名称使用 Unicode NFC 规范化。一个目录中的正常文件和文件夹共享名称空间；比较忽略大小写及组合重音，避免跨平台导出时冲突。

## 新建目录

`POST /file/newFolder`，兼容旧拼写 `/file/newFoloder`。参数：`filePid`、`fileName`。

`filePid=0` 表示根目录；其他父目录必须属于当前用户、是正常文件夹，且每一层祖先均正常。与现有正常文件或目录重名时拒绝创建。回收站项不会占用正常目录名称。

## 重命名

`POST /file/rename`，参数：`fileId`、`fileName`。

**fileName 是完整名称，前端应显示并提交扩展名。** 例如 `report.pdf → final.pdf` 提交 `final.pdf`，后端不会重复附加 `.pdf`。显式提交 `final.txt` 或无扩展名会按输入重命名；重命名仅改变显示名和下载名，不转换内容、不重建缩略图或视频分片，也不修改已保存的内容类型。相同名称是成功的无操作；纯大小写修改允许；与其他项重名则拒绝。正在处理的文件需等待处理完成。

## 批量移动

`POST /file/changeFileFolder`，参数：`fileIds`（逗号分隔，最多 500 项）、`filePid`。

先验证全部源项及目标，再在一个数据库事务内移动。目标必须是当前用户正常目录；禁止移动到自身、后代或普通文件下。任何越权、缺失、无效状态或数据库错误使整批失败。选中父目录及其子项时只移动父目录，保留内部结构；移动到当前所在目录不改名。

同名自动添加 ` (1)`、` (2)` 等唯一后缀，文件后缀保留。例如目标已有 `report.txt`，两项同名文件依次变为 `report (1).txt` 与 `report (2).txt`。超长名称只截短主名称，不截断扩展名；若扩展名过长以至于不能容纳唯一后缀，则拒绝整批操作并提示先重命名。

## 目标目录选择

`GET /file/loadAllFolder`，参数：`filePid`、可选 `currentFileIds`。

返回当前父目录的正常子目录，排除所有选中目录。直接请求选中目录或其后代内部时返回空列表，避免选择会产生循环的目标。不存在、外部用户或已删除目标会被拒绝。

## 文件列表

`GET /file/loadDataList` 支持以下公开参数：

| 参数 | 规则 |
| --- | --- |
| `filePid` | 指定目录时仅查其直接子项；普通浏览省略时默认为根目录。分类或搜索时省略则跨目录查询。 |
| `category` | `all`、`video`、`music`、`image`、`doc`、`others`。未知值返回参数错误。 |
| `fileNameFuzzy` | 文件名文字包含搜索，最长 200 字符。`%`、`_`、`!` 按普通文字处理，不作 SQL 通配符。 |
| `folderType` | 可选，0 文件、1 目录。 |
| `fileType` | 可选，1 至 10，保持现有类型枚举。 |
| `status` | 可选，0 处理中、1 处理失败、2 可用。 |
| `sortField` | `fileName`、`fileSize`、`createTime`、`lastUpdateTime`；默认 `lastUpdateTime`。 |
| `sortDirection` | `asc` 或 `desc`，默认 `desc`。目录始终优先，相同排序值用 fileId 保持稳定顺序。 |
| `pageNo` | 正整数，默认 1；超过末页时返回末页。 |
| `pageSize` | 正整数，默认 20；上限 100，超出上限按 100。 |

客户端 `userId`、`delFlag`、`orderBy`、`filePath` 等内部字段不会绑定到查询。列表只返回当前用户的正常文件 VO，不返回物理路径和 MD5。空结果保留分页结构，`pageTotal=1`。
